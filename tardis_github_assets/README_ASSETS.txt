GITHUB ASSET PACK - 10th Doctor TARDIS

Upload every file in this folder to the same GitHub directory.

Main model:
  Tardis.obj

Material groups used by the OBJ:
  Material.003 = detailed police-box exterior
  Material.001 = secondary material
  Material.002 = secondary material

Textures:
  Material001_BaseColor.png
  Material001_Normal.png
  Material002_BaseColor.png
  Material002_Normal.png
  Material003_BaseColor.png
  Material003_Normal.png
  Material003_Emissive.png

The normal files are the supplied OpenGL normal maps.
The OBJ has been triangulated and centered, and scaled to about 66 x 66 x 130 units,
which is close to the dimensions of the older Starfall TARDIS model.

Tardis.mtl is included for normal 3D viewers. Starfall does not need to fetch it if
your script assigns materials itself.
